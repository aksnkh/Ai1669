# Ai1669

سرویس CallCenter یک API در ASP.NET Core 8 است. فایل صوتی فارسی را به OpenAI می‌فرستد، نام شهر را در متن با فهرست شهرها تطبیق می‌دهد و پاسخ فارسی را با صدای زن به‌صورت MP3 برمی‌گرداند.

## نصب و اجرا

.NET 8 SDK و Visual Studio 2022 نسخهٔ 17.8 یا جدیدتر را نصب کنید. برای اجرای HTTPS محلی در ویندوز، به گواهی توسعه اعتماد کنید:

```powershell
dotnet dev-certs https --trust
dotnet restore Ai1669.sln
dotnet build Ai1669.sln --no-restore
dotnet user-secrets set "OpenAI:ApiKey" "<your OpenAI API key>" --project src/CallCenter
dotnet run --project src/CallCenter
```

در Visual Studio، فایل `Ai1669.sln` را باز کنید و پروژهٔ CallCenter را اجرا کنید. صفحهٔ میکروفون از نشانی اصلی باز می‌شود. Swagger در محیط Development در `https://localhost:7209/swagger` باز می‌شود. در محیط اجرا می‌توانید کلید را از طریق متغیر `OpenAI__ApiKey` و سامانهٔ مدیریت اسرار تزریق کنید. در صورت نیاز، از `appsettings.Development.json.example` برای تنظیم مدل و صدا استفاده کنید.

## API

`POST /api/voice-coverage` یک فیلد `audio` از نوع `multipart/form-data` دریافت می‌کند. فایل‌های WAV، MP3، MPGA، MPEG، M4A، MP4، WEBM، FLAC و OGG تا سقف ۲۴ MiB پذیرفته می‌شوند.

```powershell
curl.exe --fail -F "audio=@sample.wav" https://localhost:7209/api/voice-coverage --output reply.mp3
```

پاسخ موفق `audio/mpeg` است. هدر `X-Coverage-Status` یکی از مقادیر `Active`، `Inactive`، `UnknownCity`، `MultipleCities` و `NoSpeech` را نشان می‌دهد. هدر `X-Audio-Generated-By: AI` نشان می‌دهد که صدا مصنوعی است. رابط کاربر باید هنگام پخش این موضوع را به کاربر اطلاع دهد. خطاهای HTTP در قالب Problem Details گزارش می‌شوند.

| شناسه | شهر | خدمات فعال |
| --- | --- | --- |
| 1 | بندرعباس | بله |
| 2 | تهران | بله |
| 3 | شیراز | خیر |

تبدیل گفتار با `gpt-4o-transcribe` و تولید صدا با `gpt-4o-mini-tts` و صدای `nova` انجام می‌شود. فایل ورودی و متن پاسخ برای پردازش به OpenAI ارسال می‌شوند.

اگر نام شهر در فهرست پوشش پیدا نشود، متن به `gpt-4.1-mini` فرستاده می‌شود تا نام شهرهای ایران را از همان جمله استخراج کند. شهر تشخیص‌داده‌شده‌ای که در فهرست پوشش نیست، مانند رشت، وضعیت `Inactive` می‌گیرد. اگر نام شهر مشخص نباشد، برنامه از کاربر می‌خواهد دوباره بگوید.

## ساختار

تنها پروژهٔ Solution در `src/CallCenter` قرار دارد. Controller فایل را اعتبارسنجی می‌کند و عملیات را به Application می‌سپارد. Application از قراردادهای تبدیل گفتار، تولید صدا و خواندن شهرها استفاده می‌کند. Infrastructure کلاینت OpenAI و مخزن درون‌حافظه‌ای را فراهم می‌کند. برای اتصال آتی به SQL Server، پیاده‌سازی `ICityRepository` را جایگزین و ثبت آن را در `Program.cs` تغییر دهید.

اگر در تنظیمات محلی یا متغیر محیطی `OpenAI__TranscriptionModel` مدل دیگری گذاشته‌اید، برای استفاده از مدل پیش‌فرض جدید، آن مقدار را به `gpt-4o-transcribe` تغییر دهید.

## گفت‌وگوی زنده با میکروفون

پس از اجرای پروژه، صفحهٔ اصلی `https://localhost:7209/` را در Chrome یا Edge باز کنید، روی **آماده‌سازی میکروفون** بزنید و اجازهٔ میکروفون بدهید. بعد از فعال شدن **حالا صحبت کنید**، روی آن بزنید و برای نمونه بپرسید «در بندرعباس خدمات دارید؟». متن هنگام صحبت ظاهر می‌شود. پس از پایان جمله، میکروفون بسته می‌شود و پاسخ فارسی پخش می‌شود. پس از حدود ۱٫۲ ثانیه سکوت، جمله برای تشخیص نهایی ارسال می‌شود. برای سؤال بعدی دوباره **آماده‌سازی میکروفون** را بزنید. اگر مرورگر پخش خودکار را مسدود کرد، از کنترل پخش استفاده کنید.

مرورگر صدا را بدون ساخت فایل، از طریق WebRTC به OpenAI می‌فرستد. سرور از همان کلید `OpenAI:ApiKey` برای صدور توکن کوتاه‌عمر استفاده می‌کند و فقط توکن موقت را به مرورگر می‌دهد. مسیرهای جدید عبارت‌اند از:

- `POST /api/voice-coverage/realtime/session` با بدنهٔ `{"language":"fa"}` برای توکن جلسهٔ رونویسی.
- `POST /api/voice-coverage/text` با بدنهٔ `{"transcript":"در تهران خدمات دارید؟"}` برای دریافت MP3 و وضعیت پوشش.

گفت‌وگوی زنده در Development فعال است. برای استقرار، صفحه به HTTPS و مرورگر و سرور هر دو به دسترسی مناسب به OpenAI نیاز دارند. ابتدا مسیرهای هزینه‌دار را پشت احراز هویت و محدودیت مصرف قرار دهید، سپس `Realtime__Enabled=true` را تنظیم کنید. محدودیت فعلی مسیرهای زنده ۲۰ درخواست در دقیقه به‌ازای IP است.

برای مقایسهٔ مدل زنده، می‌توانید در **Manage User Secrets** مقدار `OpenAI:RealtimeTranscriptionModel` را روی `gpt-live-transcribe` بگذارید. این تنظیم فقط روی میکروفون اثر دارد. برای برگشت به مدل پیش‌فرض `gpt-4o-transcribe`، همین تنظیم را حذف کنید. برای مقایسه، در هر دو مدل جمله‌های فارسی یکسان را با همان میکروفون بگویید و دقت نام شهر و زمان انتظار را بسنجید.
